# Flip Deck

Launcher สำหรับ SHARP NP601SH (Android 5.1.1) ใช้ปุ่มทิศทางและ OK เลือกเมนูได้

## ปุ่มควบคุม

- กด **0–9**, **\*** หรือ **#** จาก Flip Deck เพื่อเปิดหน้ากดโทรพร้อมตัวที่กด แล้วพิมพ์เลขต่อหรือโทรได้
- จากหน้า Home ที่โชว์รูป กด **ขึ้น** เพื่อเปิดรายการแจ้งเตือนของระบบ; ใช้ขึ้น/ลงและ OK เลือกแจ้งเตือน และ Back กลับ Home
- ในหน้ารายการและตาราง ปุ่มทิศทางเลื่อนรายการ และ **OK** เปิดรายการที่เลือก; แตะพื้นที่รูปเพื่อดูตาราง Home
- **Menu** เปิดหรือปิดหน้าเครื่องมือ; **Back** กลับหน้าโชว์รูป
- ปุ่ม Back ใช้คำสั่งย้อนกลับของ Android ตามหน้าปัจจุบัน รวมถึงปิดเมนูหรือคีย์บอร์ด; FlipDeck ไม่ดัก Back จากแอพอื่น
- ปุ่ม **I**, **II**, **III** เป็น Quick Start ของเครื่อง ตอนนี้ตั้งไว้เป็น **Flip Deck Home**, **Flip Deck Tools**, **Flip Deck Tasks** ตามลำดับ ปุ่ม III เปิดหน้าแอพล่าสุด กด Options > Delete one หรือ Delete all เพื่อเคลียร์รายการแอพ เปลี่ยนการกำหนดปุ่มได้ใน Settings > Quick Start Key
- ปุ่มโทร ข้อความ เว็บ และกล้องที่มีไอคอนบนเครื่องยังใช้ตามหน้าที่เดิม โดยปุ่มกล้องเปิด Flip Cam
- ปุ่ม End/Close กดสั้นเพื่อออกจากหน้าปัจจุบันและกลับ Home ได้ทั่วระบบ; หน้าแอพล่าสุดอยู่ที่ปุ่ม III

หน้าโชว์รูปแสดงเวลา วันที่ แบตเตอรี่ Bluetooth และ Wi-Fi เลือกรูปพื้นหลังที่หน้าเครื่องมือ > Wallpaper > Choose photo (phone / SD) ได้ จากตัวเลือกไฟล์ให้เปิด Category > microSD แล้วเลือกรูปใน SD card
รูปพื้นหลังแสดงครบทั้งภาพโดยคงสัดส่วนเดิม ถ้าสัดส่วนรูปไม่ตรงกับหน้าจอจะมีพื้นที่สีเข้มด้านข้างหรือด้านบนล่าง
การเลือกรูปจาก Quick Tools ผ่านปุ่ม II จะใช้รูปและโหมดแสดงเดียวกับหน้า Home และอัปเดตให้ตรงกันเมื่อสลับกลับมาจากแอพอื่น

ปุ่มลัด F1–F4 (เมล เว็บ Voice Type และกล้อง) เปิดแอพเฉพาะหน้า Home ที่โชว์รูปหรือตาราง Home ของ FlipDeck บริการ Accessibility ไม่ดักปุ่มจากแอพอื่น

## Voice Type (F3)

F3 จาก Home เปิดหน้าเตรียมพิมพ์ด้วยเสียง เลือกภาษาไทย `th-TH` หรืออังกฤษ `en-US` แล้วกด Speak/F3 เพื่อเรียกตัวถอดเสียงที่ติดตั้งอยู่ ผลลัพธ์ตรวจแก้ คัดลอก หรือแชร์ได้ เก็บข้อความไว้เมื่อออกจากหน้าและไม่เริ่มอัดเสียงเพียงเปิดหน้า รายการ All Apps ยังเปิดจากช่อง APPS บน Home ได้

NP601SH เครื่องทดสอบยังไม่มี Activity ที่รับ `android.speech.action.RECOGNIZE_SPEECH` และยังไม่มีตัวถอดเสียงไทย/อังกฤษ หน้านี้จะแจ้งว่าต้องตั้ง engine ก่อน ยังไม่ได้ทดสอบเสียงหรือความแม่น รอเลือกวิธีเชื่อมต่อคอมช่วยถอดเสียงหรือบริการออนไลน์เพื่อทำส่วนนี้ต่อ

หน้าแจ้งเตือนจากปุ่มขึ้นและหน้าแอพล่าสุดจากปุ่ม III ใช้บริการ Accessibility ชื่อ **Flip Deck shortcuts** ซึ่งต้องเปิดใน Settings > Accessibility หลังติดตั้งใหม่

## ติดตั้ง

APK: [`dist/Flip-Deck-NP601SH.apk`](dist/Flip-Deck-NP601SH.apk)

```powershell
.\Build.ps1 -Install
```

Flip Deck เป็น Home เริ่มต้นบนเครื่องทดสอบ หากต้องการกลับไปใช้ launcher เดิม ให้เข้า Settings > Other settings > Application > Flip Deck > Clear defaults แล้วกด Home เพื่อเลือกใหม่

`Build.ps1 -Install` ตั้งค่าระบบ `end_button_behavior=1` เพื่อให้ปุ่ม End/Close กลับ Home จากทุกแอพ โดยใช้การจัดการปุ่มของ Android เอง แอพที่ออกยังอาจทำงานเบื้องหลัง การทดสอบบน NP601SH ด้วย key event ENDCALL ผ่านจาก Settings, Flip Browse และหน้าเขียนข้อความ Flip Post

# Flip Deck

Launcher สำหรับ SHARP NP601SH (Android 5.1.1) ออกแบบให้ใช้ปุ่มกดได้โดยไม่ต้องแตะจอ

- หน้าแรก: กดเลข **1–9** เพื่อเปิด โทรศัพท์, ข้อความ, รายชื่อ, เพลง, กล้อง, รูปภาพ, เบราว์เซอร์, ตั้งค่า และแอพทั้งหมด
- กด **0** หรือ **Menu** เพื่อเปิดเครื่องมือด่วน: Bluetooth, Wi-Fi, เสียง, หน้าจอ, ไฟล์, ปฏิทิน, Pocket Music, Pocket Hearts
- กด **#** เพื่อเปิดรายชื่อแอพทั้งหมด เลื่อนด้วยปุ่มทิศทาง และกด **OK** เพื่อเปิด
- กด **\*** หรือ **Back** เพื่อกลับหน้าแรก
- เวลา วันที่ แบตเตอรี่ สถานะ Bluetooth และ Wi-Fi แสดงบนหน้าแรก

ติดตั้ง APK: [`dist/Flip-Deck-NP601SH.apk`](dist/Flip-Deck-NP601SH.apk)

สร้างและติดตั้งใหม่:

```powershell
.\Build.ps1 -Install
```

เมื่อกด Home หลังติดตั้ง Android จะให้เลือก launcher เริ่มต้น หากต้องการกลับไปใช้ launcher เดิม ให้เปลี่ยนใน Settings > Home หรือ Settings > Apps > Default apps / Home app ตามเมนูของเครื่อง

# Flip Post — SHARP NP601SH

แอพรวมข้อความ SMS และกล่องเข้าอีเมล IMAP สำหรับ Android 5.1.1 ใช้ปุ่มกดของ NP601SH รองรับการตั้งตัวอักษรใหญ่ของเครื่องโดยจัดขนาดแถบควบคุมให้พอดีจอ

## ปุ่มซองจดหมาย

- ปุ่มรูปซองจดหมาย/F1 จากหน้า Home ของ FlipDeck เปิด Flip Post
- เมื่ออยู่ใน Flip Post และไม่ได้อยู่ในคีย์บอร์ด กด F1 กลับกล่อง SMS พร้อมเก็บฉบับร่าง
- ซ้าย/ขวาที่กล่องเข้า: สลับ SMS / MAIL
- ขึ้น/ลง + OK: เลือกรายการและเปิดอ่าน
- Menu: เขียนข้อความ, รีเฟรช, ตั้งบัญชีเมล และตั้งแจ้งเตือน
- Back: กลับกล่องเข้า; จากหน้าเขียน SMS จะเก็บฉบับร่าง
- ช่องผู้รับ: กดตัวเลขโดยตรง, 0 ค้างเพื่อใส่ `+` เมื่อเริ่มเบอร์, Delete ลบเลข, OK ไปช่องข้อความ; Back เก็บร่างและกลับกล่องเข้า

FlipDeck รับ F1 เพื่อเปิดเมลเฉพาะหน้า Home และไม่ดักปุ่มขณะใช้งานแอพอื่น

## SMS

- อ่านบทสนทนาจากฐานข้อมูล SMS ของเครื่อง จัดกลุ่มผู้ส่ง แสดงตัวอย่างและจำนวนข้อความที่ยังไม่อ่านใน Flip Post
- กล่องเข้าอ่าน 5,000 ข้อความล่าสุด สูงสุด 200 บทสนทนา; เปิดบทสนทนาแสดง 100 ข้อความล่าสุด
- แจ้งเตือน SMS ใหม่จาก `SMS_RECEIVED` โดยไม่แสดงเนื้อหาข้อความในหน้าล็อก
- เขียนข้อความ เก็บฉบับร่าง และแบ่งข้อความยาวตาม `SmsManager` พร้อมแสดงจำนวนส่วนก่อนส่ง
- เก็บฉบับร่างอัตโนมัติหลังแก้ข้อความ หรือเลือก Save draft; ล้างได้จาก Menu > Discard draft
- ต้องยืนยัน Send ก่อนส่งจริง ถ้าส่งล้มเหลวจะเก็บฉบับร่างไว้
- ทางเลือกส่งข้อความใน Flip Phone เปิดหน้าเขียน SMS ของ Flip Post พร้อมเบอร์

แอพ SMS ของ SHARP ยังเป็นผู้รับ/บันทึก SMS และ MMS ตามระบบ Flip Post ไม่เปลี่ยน default SMS และไม่เขียนหรือลบข้อมูลในฐาน SMS การเปิดอ่านข้อความจะเก็บสถานะว่าอ่านแล้วใน Flip Post เท่านั้น แจ้งเตือนของแอพเดิมอาจยังแสดงอยู่ MMS/ไฟล์แนบเปิดผ่าน Menu > System SMS / MMS app

## Mail

รองรับบัญชี **IMAP over TLS ที่พอร์ต 993** และการยืนยันตัวตนด้วยรหัสผ่านเฉพาะแอพ หรือบัญชี IMAP ที่ผู้ให้บริการยังอนุญาตการยืนยันตัวตนแบบนี้

1. เปิด MAIL > Set up mail account
2. ใส่ IMAP host, email/username และ app password บนโทรศัพท์
3. เลือก Save เพื่อเก็บบัญชีแล้วเชื่อมต่อ

สำหรับ Gmail ใช้ `imap.gmail.com` และ App Password ของบัญชีที่เปิด 2-Step Verification และมีสิทธิ์ใช้ App Password ไม่ใช้รหัสผ่านบัญชี Google ตามปกติ บัญชีที่บังคับ OAuth เช่น Outlook/Exchange Online ไม่รองรับในหน้าตั้งค่านี้

- แสดงหัวข้อ 50 ฉบับล่าสุด โหลดเนื้อหาตอนเปิดอ่าน
- ดูข้อความเป็นตัวหนังสือ ไม่โหลดรูปภายนอกหรือไฟล์แนบ
- แสดงเนื้อหาสูงสุด 32,000 ตัวอักษรต่อฉบับ และเก็บข้อความที่เปิดแล้วไว้สูงสุด 50 ฉบับเพื่ออ่านออฟไลน์
- เปิดกล่อง IMAP แบบ read-only จึงไม่ลบเมลหรือเปลี่ยนสถานะอ่านแล้วบนเซิร์ฟเวอร์
- ตรวจใบรับรองและชื่อเซิร์ฟเวอร์ ใช้ TLS 1.2
- รหัสผ่านเข้ารหัสด้วย RSA ใน AndroidKeyStore; หากเก็บแบบปลอดภัยไม่ได้ จะไม่บันทึกบัญชี
- Menu > Mail check every 30 min เปิด/ปิดงานเช็กเมลเป็นช่วง ๆ ผ่าน JobScheduler เริ่มต้นปิดไว้ งานทำเมื่อมีเครือข่าย ไม่มีการค้าง IMAP IDLE ตลอดเวลา
- Menu > Remove mail account ลบข้อมูลเข้าระบบและแคชเมลจากโทรศัพท์

เป็นกล่องรับ/อ่านอีเมล ยังไม่มีตัวส่งเมล SMTP

## สร้างและติดตั้ง

ใช้ SDK และ signing key ร่วมกับแอพอื่นใน `Flip Phone`:

```powershell
.\Build.ps1 -Install
```

APK: [dist/Flip-Post-NP601SH.apk](dist/Flip-Post-NP601SH.apk)

JavaMail for Android และ Activation 1.6.7 อยู่ใน `lib`; รวมใบอนุญาตไว้ใน `assets/licenses` ของ APK ดูรายละเอียด [lib/README.md](lib/README.md)

## ผลตรวจ

- บิลด์ ตรวจลายเซ็น และติดตั้งบน NP601SH สำเร็จ
- ทดสอบ F1/ปุ่มซองจดหมายจาก Home ของ FlipDeck เปิด Flip Post ได้; ร่างข้อความยังอยู่หลังปิดแอพและเปิดใหม่ และลบร่างทดสอบแล้ว
- ทดสอบบนเครื่องด้วยข้อมูลจำลอง: จัดกลุ่ม SMS/นับข้อความไม่อ่าน/เรียงบทสนทนา, เมลภาษาไทย UTF-8, HTML เป็นข้อความ, multipart เลือก plain text, ข้ามไฟล์แนบ และจำกัดเนื้อหา
- ทดสอบ AndroidKeyStore เข้ารหัส/ถอดรหัสบนเครื่องจริงผ่าน ไม่บันทึกรหัสทดสอบหรือข้อความทดสอบลงฐาน SMS
- ยังไม่ได้ทดสอบรับ/ส่ง SMS ผ่านเครือข่าย เพราะเครื่องไม่มี SIM และยังไม่ได้เชื่อมต่อบัญชีเมลจริงเพราะยังไม่มีบัญชีและ Wi-Fi ที่เชื่อมต่อ

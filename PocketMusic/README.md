# Pocket Music สำหรับ NP601SH

แอพปุ่มกดสำหรับเปิดการตั้งค่า Bluetooth และเว็บไซต์ YouTube Music ผ่าน Firefox

- กด **1** เพื่อเปิดหน้า Bluetooth แล้วเลือกจับคู่หูฟัง
- กด **2** เพื่อเปิด `music.youtube.com` ใน Firefox
- กด **3** เพื่ออัปเดตสถานะ Bluetooth และหูฟัง Sony ที่จับคู่แล้ว

NP601SH ใช้ Android 5.1.1 ซึ่งต่ำกว่าขั้นต่ำของแอพ YouTube Music รุ่นปัจจุบัน จึงใช้ทางเว็บแทน ติดตั้ง Firefox 143 รุ่น ARMv7 จาก Mozilla ให้แล้ว โดยการเปิดครั้งแรกต้องผ่านหน้าต้อนรับของ Firefox บนเครื่องก่อน แอพนี้ไม่ได้ดึงเพลงจาก YouTube โดยตรง และต้องมีอินเทอร์เน็ต การเล่นเพลงผ่านเว็บและการเล่นเมื่อปิดฝายังต้องทดสอบเมื่อโทรศัพท์ต่อ Wi-Fi หรือเน็ตมือถือ

การจับคู่หูฟังต้องให้หูฟังอยู่ในโหมด pairing ก่อน สำหรับ WF-1000XM5 ให้ใส่หูฟังในเคส เปิดฝา แล้วกดปุ่มด้านหลังเคสค้างประมาณ 5 วินาทีจนไฟสีน้ำเงินกะพริบ จากนั้นเลือก `WF-1000XM5` ในหน้า Bluetooth ของโทรศัพท์

สร้างและติดตั้งใหม่จาก PowerShell:

```powershell
.\Build.ps1 -Install
```

ไฟล์ APK อยู่ที่ [`dist/Pocket-Music-NP601SH.apk`](dist/Pocket-Music-NP601SH.apk)

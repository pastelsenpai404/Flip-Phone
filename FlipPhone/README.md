# Flip Phone — SHARP NP601SH

แอพโทรศัพท์สำหรับปุ่มกดของ NP601SH ใช้ Java/Canvas ไม่มีไลบรารีเสริมหรือบริการเบื้องหลัง อ่านรายชื่อและประวัติการโทรจากเครื่องผ่าน worker ตัวเดียว ไม่โหลดรูปประจำรายชื่อ

## หน้าจอและปุ่ม

- **DIAL**: พิมพ์เบอร์ด้วย 0–9, `*`, `#`; กด 0 ค้างเมื่อเริ่มเบอร์เพื่อใส่ `+`
- **CALLS**: ประวัติ 100 สายล่าสุด พร้อมประเภทสาย เวลา และระยะเวลา สายไม่ได้รับแสดงสีแดง
- **PEOPLE**: รายชื่อและเบอร์จากสมุดโทรศัพท์ รวมเบอร์หลายเบอร์ของแต่ละคน ค้นหาชื่อหรือเบอร์จาก Menu
- **STARS**: รายการโปรดสูงสุด 40 เบอร์ บันทึกไว้ในแอพ
- ซ้าย/ขวา: สลับแท็บ; ขึ้น/ลง: เลือกรายการ
- ปุ่มโทรสีเขียว: โทรหาเบอร์ที่พิมพ์หรือรายการที่เลือก
- OK บน DIAL: โทร; OK ในรายการ: เปิดเมนูรายละเอียด
- Back บน DIAL: ลบตัวท้าย; กดค้างเพื่อล้างเบอร์; ถ้าไม่มีเบอร์จะออก
- Back ในรายการ: กลับ DIAL; Back ในเมนู: ปิดเมนู
- Menu: ค้นหารายชื่อ, เพิ่ม/ลบโปรด, ส่งข้อความ, บันทึกผู้ติดต่อ, รีเฟรช, ล้างเบอร์ และออก

จาก **FlipDeck Home** ปุ่มโทรเปิดแอพนี้ และการกดตัวเลข/`*`/`#` เปิดแอพพร้อมตัวแรกที่กด การเปิดรายชื่อจาก FlipDeck เข้าหน้า PEOPLE

## ระบบโทรศัพท์

กดปุ่มโทรแล้วส่ง `ACTION_CALL` ให้ระบบโทรศัพท์ หน้ารับสายและควบคุมสาย เช่น วางสาย ลำโพง และ Bluetooth เป็นหน้าของระบบ SHARP เบอร์ฉุกเฉินที่ Android ระบุจะเปิดหน้ากดเบอร์ของระบบเพื่อให้ผู้ใช้โทรต่อ

เครื่องนี้ใช้ Android 5.1.1/API 22 ส่วน API เปลี่ยน default dialer แบบมาตรฐานเริ่มที่ API 23 จึงผูกทางเข้าจาก FlipDeck และรับ `tel:`/`ACTION_DIAL` โดยไม่แก้แอพระบบ

ถ้าไม่มี SIM จะแสดง NO SIM และไม่เริ่มโทรเบอร์ปกติ รายชื่อ ประวัติ และการตั้งรายการโปรดใช้งานได้ออฟไลน์

สิทธิ์: `CALL_PHONE`, `READ_CONTACTS`, `READ_CALL_LOG` ไม่ขอสิทธิ์อินเทอร์เน็ต ไม่เขียนหรือลบประวัติการโทร การเพิ่มรายชื่อและส่งข้อความเปิดแอพที่ติดเครื่องเพื่อให้ผู้ใช้ทำต่อ

## สร้างและติดตั้ง

ใช้ SDK และ signing key ร่วมกันในโฟลเดอร์ `Flip Phone`:

```powershell
.\Build.ps1 -Install
```

APK: [dist/Flip-Phone-NP601SH.apk](dist/Flip-Phone-NP601SH.apk)

## ผลตรวจบน NP601SH

ติดตั้งและตรวจลายเซ็น APK สำเร็จ ทดสอบเลข 0–9, `*`, `#` จาก Home, ลบเลข, สลับแท็บ, อ่านประวัติสาย, หน้าไม่มีรายชื่อ, เพิ่ม/ลบรายการโปรดและเปิดแอพใหม่เพื่อตรวจการบันทึกแล้ว ปุ่มโทรจาก FlipDeck เปิด DIAL และทางลัดรายชื่อเปิด PEOPLE รายการทดสอบถูกลบออกแล้ว ยังไม่ได้ทดสอบโทรจริงเพราะเครื่องไม่มี SIM

อ้างอิง: [Android common intents](https://developer.android.com/guide/components/intents-common), [TelecomManager](https://developer.android.com/reference/android/telecom/TelecomManager), [CallLog.Calls](https://developer.android.com/reference/android/provider/CallLog.Calls)
